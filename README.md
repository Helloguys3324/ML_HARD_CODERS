3. **Causal Statistics & Graph Theory:**
   - **Simpson's Paradox (`task_portugal`):** Revealing how Douro valley subregions completely reverse drip-irrigation effectiveness within every single microclimate.
   - **Bilingual Graph Normalization (`task_finland`):** Disambiguating 422 raw Swedish/Finnish town names into a canonical 116-node, 448-edge maritime network.

4. **Reinforcement Learning & Planning:**
   - **Braided River Navigation (`task_new_zealand`):** State-expanded $A^*$ search over 4.7M states `(cell, tide_phase, bridge_mask)` solving the 296-minute river crossing in 0.5s.
