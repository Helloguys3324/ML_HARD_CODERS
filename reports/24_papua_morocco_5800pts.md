## 1. `task_papua_new_guinea` — `SIGMOID_ELIGIBILITY` (200)

Задача: превзойти «ангкола» в 1.5× по рыбе/день на невиданных днях.

**Ключевой вывод:** среда — конечный MDP `(row, col, hold, steps_left)` × 24 шага, все случайности (`bite`/`tide`) берутся из `random.Random(seed)` дня. Грейдер разыгрывает политику на скрытых seed, поэтому единственная робастная стратегия — **детерминированная ожидаемо-оптимальная**.

Поэтому вместо BC/DAgger/offline-RL сделана **точная обратная итерация по значениям (value iteration)** на ожидаемых переходах:

- ангкол работает в зарослях `s` (bite 0.20) → 2.49–2.56 рыбы/день;
- VI выбирает внешний риф `T` (bite 0.90) → **5.97 рыбы/день**.

Итог: **5.968 против 2.558 = 2.333×** (нужно ≥1.5×) на 252 невиданных днях калибратора. Сабмит — самодостаточный `main.py` со сжатой таблицей всех 6048 состояний.

## 2. `task_morocco` — `SIGMOID_ROUTING` (200)

Два гейта одновременно: quality ≥ 0.80 и cost ≤ 10000 (⇔ ≤ 395 дорогих из 500).

**Сигнал из 400 трейновых примеров:** точность гидов зависит от *типа* вопроса:

| Тип | дешёвая (0.5B) | дорогая (7B) |
|---|---|---|
| прямой lookup по доске | 100% | ~100% |
| умножение / min-max | слабо | ~100% |
| время с паузой | — | ~66% |
| кратчайший путь «в обход» | плохо | ~10% |

Самый ценный признак — **самому посчитать кратчайший путь** (Дейкстра на stdlib): если прямое ребро уже кратчайшее → дорогая ~89%, если обход короче → обе плохи.

Роутер: `value = P(correct|expensive) − P(correct|cheap)`, сортировка по убыванию, дорогому гиду — топ-⌊19N/24⌋. Это даёт гарантию бюджета при любом N:

```text
cost = N + 24E ≤ 20N
```

Результат на скрытых 500: **quality 0.8520**, **cost 9980** → PASS.
