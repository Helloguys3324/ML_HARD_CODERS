## 2. Fastest credible baseline (2–5 min)

Classical image features + LightGBM. No pretrained weights, no GPU:

```python
# work/cv_classical.py — run from the challenge directory
import numpy as np, polars as pl, cv2, lightgbm as lgb
from pathlib import Path
from sklearn.model_selection import StratifiedKFold
from sklearn.metrics import roc_auc_score

def feats(p):
    im = cv2.imread(str(p), cv2.IMREAD_COLOR)
    if im is None: return np.zeros(72, np.float32)
    im = cv2.cvtColor(im, cv2.COLOR_BGR2RGB)
    h, w = im.shape[:2]; g = cv2.cvtColor(im, cv2.COLOR_RGB2GRAY)
    out = [w, h, w / max(h, 1), Path(p).stat().st_size]
    for c in range(3):
        ch = im[:, :, c].astype(np.float32)
        out += [ch.mean(), ch.std(), np.percentile(ch, 10), np.percentile(ch, 90)]
        out += np.histogram(ch, bins=16, range=(0, 256))[0].tolist()
    out += [g.mean(), g.std(), cv2.Laplacian(g, cv2.CV_32F).var(),
            (cv2.Canny(g, 80, 160) > 0).mean(), float(np.log1p(g.std()))]
    hsv = cv2.cvtColor(im, cv2.COLOR_RGB2HSV)
    out += [hsv[:, :, 1].mean(), hsv[:, :, 1].std(), hsv[:, :, 2].mean()]
    return np.asarray(out, np.float32)

tr = pl.read_csv("data/train.csv"); te = pl.read_csv("data/test.csv")
X = np.stack([feats(Path("data") / p) for p in tr["image"]])
Xte = np.stack([feats(Path("data") / p) for p in te["image"]])
y = tr["target"].to_numpy()
skf = StratifiedKFold(5, shuffle=True, random_state=42)
oof = np.zeros(len(y)); pred = np.zeros(len(te))
for i_tr, i_va in skf.split(X, y):
    m = lgb.LGBMClassifier(n_estimators=600, learning_rate=0.05, num_leaves=63,
                           n_jobs=4, verbose=-1).fit(X[i_tr], y[i_tr])
    oof[i_va] = m.predict_proba(X[i_va])[:, 1]
    pred += m.predict_proba(Xte)[:, 1] / 5
print("OOF AUC", roc_auc_score(y, oof))
pl.DataFrame({"id": te["id"], "target": pred}).write_csv("submissions/submission.csv")
```

This runs in ~1–3 min for 2k images and is a real baseline on texture/color tasks.

## 3. Best CPU model

1. **Classical features + LGB/Ridge** (above): fastest and surprisingly strong on
   small, low-resolution, color/texture datasets.
2. **Frozen pretrained embeddings + Ridge/LogReg** — only if pretrained is allowed.
   Extract once with `timm` at 128–224 px, L2-normalize, concat 1–2 backbones,
   then linear probe. 5–15 min for 5k images; no backprop.
3. **Scratch CNN at 96–128 px** for N ≤ 2k, 2 folds, 2–3 epochs. `resnet18` or a
   4-block CNN. Use strong aug (flip, crop, color jitter), label smoothing 0.05,
   EMA if available.
4. **Blend** classical OOF with CNN/embedding OOF; they fail differently.

**Critical:** `--mode extract_probe` with `--no-pretrained` creates a randomly
initialized backbone. Its "embeddings" are noise. Never submit that. Either pass
`--pretrained` (with permission) or use `--mode train`/classical features.

## 4. Feature engineering that pays on CPU

- Width, height, aspect ratio, file size, JPEG quality if available.
- Per-channel mean/std/percentiles + 16-bin color histograms (RGB and HSV).
- Grayscale Laplacian variance (blur), Canny edge density, gradient magnitude stats.
- Saturation/value stats; dominant color; background color (border pixels).
- EXIF orientation and camera metadata if present (use `PIL.ImageOps.exif_transpose`).
- Near-duplicate hash (`dHash`/`pHash`) and duplicate-group ID; this is both a
  feature and a CV grouping key.
- If text/OCR is present, a TF-IDF side model can add signal cheaply.

---

## 5. Validation

- Split by **near-duplicate group**, not by image. Photos of the same object/site
  leak across folds. Compute dHash and cluster at Hamming distance ≤ 4–6, then
  `StratifiedGroupKFold`.
- For video frames, split by video ID. For medical images, split by patient ID.
- Check class balance per fold; use `StratifiedKFold` otherwise.
- Run adversarial validation on image features (or embeddings) if train/test come
  from different sources.
- TTA: hflip is safe; D4 (8 views) is rarely worth 8× CPU inference.

---

## 6. Common pitfalls

| Pitfall | Symptom | Fix |
| :--- | :--- | :--- |
| `extract_probe --no-pretrained` | CV ≈ random | Use pretrained (if allowed) or train mode |
| BGR/RGB mismatch | Poor accuracy vs a known-good model | `cv2.cvtColor(..., COLOR_BGR2RGB)`; PIL is RGB |
| EXIF rotation ignored | Flipped/rotated images | `ImageOps.exif_transpose` |
| Wrong normalization | Domain gap | `timm.data.resolve_model_data_config` |
| 224 px + 5 folds on CPU | Job never finishes | 96–128 px, 2 folds, 2 epochs |
| DataLoader workers oversubscribe | Slower with `--num-workers 4` | `--num-workers 0` or 2 |
| Duplicate leakage | CV 0.99, LB 0.6 | Group by dHash/video/patient |
| Segmentation/detection attempted | No valid submission | Ship baseline boxes/masks in sample format; move on |

### 7.1 Near-duplicate grouping with dHash

```python
import numpy as np, cv2
from pathlib import Path
from sklearn.model_selection import StratifiedGroupKFold

def dhash(path, size=8):
    im = cv2.imread(str(path), cv2.IMREAD_GRAYSCALE)
    im = cv2.resize(im, (size + 1, size), interpolation=cv2.INTER_AREA)
    return np.packbits(im[:, 1:] > im[:, :-1]).tobytes()

hashes = [dhash(p) for p in train_paths]
groups = np.arange(len(hashes))
for i in range(len(hashes)):
    for j in range(i):
        if sum(bin(a ^ b).count("1") for a, b in zip(hashes[i], hashes[j])) <= 4:
            groups[i] = groups[j]; break
```

## 9. Do not attempt without GPU

- 224–384 px training of ViT/ConvNeXt/EfficientNet, 5 folds, >2k images.
- YOLO/Detectron training, SAHI tiling, segmentation at 512 px.
- Video models, optical flow, 3D CNNs, NeRF/diffusion.
- D4 TTA on every model (8× inference for ~+0.5%).
- Fine-tuning foundation models with LLRD/AWP/FGM on CPU.
