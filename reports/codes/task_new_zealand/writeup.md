# The Braided River Run — writeup (`task_new_zealand`)

- **Статус:** PASS (300 / 300)
- **FLAG:** `SIGMOID_BELLMAN`

## Суть задачи

Долина-лабиринт 47×61: от `S` (вверху слева) до `G` (внизу справа) нужно пройти через 5
русел реки. Действия `U/D/L/R/W`; стоимость хода = 1 (или `swamp_cost=3` вход в болото,
`climb_cost=1` за каждый подъём), ожидание = 1. Счёт — минута прибытия в `G`.

Ограничения:
- **Подвесные мосты** (`A..I`) проходимы только когда опущены; **лебёдки** (`a..l`) при
  входе на них переключают заданные мосты (symmetric difference). Мосты стартуют поднятыми,
  кроме `I`.
- **Броды** (`~`) проходимы только при отливе: `t % 16 < 5`.
- Камень `#` и глубокая вода `=` непроходимы; после `G` действий быть не должно.

## Подход

Классический **A\*** в расширенном пространстве состояний
`(клетка, фаза прилива t mod 16, битовая маска опущенных мостов)`.

- Множество состояний: 1146 проходимых клеток × 16 фаз × 2^8 масок ≈ 4.7 млн — покрывается
  плоскими массивами `array('i')` (~40 МБ) и `heapq`.
- Переход детерминирован: стоимость и новая фаза зависят только от клетки, фазы и маски,
  поэтому узел `(cell, tmod16, mask)` корректен, а Дейкстра/A* даёт **оптимальный** путь по времени.
- **Эвристика** (допустимая): BFS-расстояние до цели по решётки, где все не-камень/не-вода
  клетки стоят 1 минуту (игнор приливов/мостов/болот/подъёмов) — нижняя граница оставшегося
  времени.
- Результат проверен штатным симулятором: `valid run: 293 minutes (246 actions)`.

`main.py` самодостаточен (stdlib): парсит `test-input.txt`, ищет путь, пишет `solution.txt`,
укладывается ~0.5 с (лимит 2 мин).
