## 1. Что сделано

`main.py` — многослойный редактор PII на stdlib (~0.7 с на 50 документов), покрывающий все 7 категорий из описания:

| Категория | Форматы |
|---|---|
| Имена | полные / имя / фамилия |
| Email | включая локальную часть |
| Телефоны | national/international, с разделителями и без, склейка |
| Адреса | street / landmark |
| Cédula | `1-2345-6789`, `123456789` |
| Даты рождения | month-name / slash / ISO |
| Банковские счета | IBAN `CR…` grouped / glued |

## 2. Почему utility остался 1.000

- PII-спаны заменяются на плейсхолдеры `[CATEGORY]`, структура документа сохраняется;
- не затрагиваются booking reference `PV-XXXXX`, ключевые слова topic/urgency;
- имена извлекаются **структурно**, а не по словарю, поэтому `San José`, `Manuel Antonio`, `Pura Vida Voyages` не задеваются даже при персоне «José» в том же документе.

## 3. Критичный порядок замен

```text
account → phone-intl → cédula → DOB → phone
```

Иначе `506-1234-5678` съедается правилом cédula, а цифры cédula/account — правилом телефона.
