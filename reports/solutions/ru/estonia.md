# Отчёт о решении: task_estonia («This Data Is Perfect!»)

## 1. Обзор задачи
- **Задача и трек:** Medium (200 баллов). Министерство цифровых технологий Эстонии разработало модель для выявления мошенничества среди e-резидентов (1 = мошенничество / fraud, 0 = легитимный / legitimate) с заявленной точностью (accuracy) **93.42%** с использованием классификатора 1-NN (`KNeighborsClassifier(n_neighbors=1)`) со `StandardScaler` по 6 числовым признакам на наборе `applications.csv` (1 971 запись).
- **Цели аудита:**
  1. Провести аудит `project_pipeline.py` и выявить три сомнительных инженерных решения.
  2. Экспериментально доказать, что два из них являются ложными следами (ловушками / decoys) и не вызывают завышения метрики.
  3. Определить истинную первопричину (утечку данных / data leakage).
  4. Исправить пайплайн валидации для вычисления несмещённой точности с помощью Leave-One-Out / групповой кросс-валидации.
  5. Отправить флаг `SIGMOID_<ACCURACY>`, где `<ACCURACY>` — истинный процент в виде целого числа.

## 2. Анализ первопричины и ключевые гипотезы
1. **Ложный след 1 (Decoy 1): Масштабирование признаков до разбиения (Pre-Split Feature Scaling):**
   - В исходном пайплайне `StandardScaler().fit_transform(X)` выполнялся на всём наборе данных до вызова `train_test_split`.
   - *Эксперимент:* Обучение `StandardScaler` строго на обучающих фолдах внутри `Pipeline` дало точность **93.67%** (дельта всего +0.25%, ровно 1 образец из 395). Масштабирование до разбиения не являлось причиной завышения метрики.
2. **Ложный след 2 (Decoy 2): Одиночное нестратифицированное случайное разбиение (Single Unstratified Random Split):**
   - Исходный код оценивался на одном `train_test_split(..., test_size=0.2, random_state=1137)`.
   - *Эксперимент:* Стандартный построчный `LeaveOneOut()` показал точность **95.94%** (стратифицированное разбиение: 93.92%). Метрика оставалась искусственно завышенной, что исключает фактор случайного смещения выборки.
3. **Реальный баг: Групповая утечка / утечка идентичности из-за удаления идентификаторов (Group / Identity Leakage via Dropped Identifiers):**
   - Инженеры удалили столбцы-идентификаторы:
     ```python
     X = df.drop(columns=["submission_id", "date_of_birth", "citizenship", "label"])
     ```
   - *Анатомия утечки:* 1 971 заявка принадлежала всего 900 уникальным лицам (`date_of_birth` + `citizenship`). 1 611 заявок являлись повторными подачами (от 2 до 4 на человека с постоянным статусом мошенничества). Признаки повторных заявок были практически идентичными (среднее внутриличностное евклидово расстояние составило 0.038 против 3.365 между разными людьми).
   - При случайном разбиении на тест **78.0% тестовых образцов (308/395)** имели соответствующие записи от того же заявителя в обучающей выборке. Классификатор 1-NN показал **100.0% (308/308)** на утёкших заявителях, но лишь **71.3% (62/87)** на действительно невиданных ранее кандидатах.
- **Решение:** Групповая валидация с использованием `LeaveOneGroupOut`, сгруппированная по `date_of_birth` + `citizenship`.

## 3. Детали реализации (`solve.py`)
- **Признаки (6 числовых):** `form_fill_seconds`, `doc_scan_quality`, `photo_match_score`, `email_domain_age_days`, `ip_geo_distance_km`, `address_history_years`.
- **Группировка:** `groups = df["date_of_birth"].astype(str) + "_" + df["citizenship"].astype(str)` (900 уникальных групп).
- **Воспроизведение бейзлайна:** Глобальный `StandardScaler` + `train_test_split(test_size=0.2, random_state=1137)` + `KNeighborsClassifier(n_neighbors=1)` воспроизвели заявленные 93.42%.
- **Честная оценка пайплайна:**
  ```python
  pipe = Pipeline([("scaler", StandardScaler()), ("knn", KNeighborsClassifier(n_neighbors=1))])
  preds_logo = cross_val_predict(pipe, X, y, groups=groups, cv=LeaveOneGroupOut(), n_jobs=-1)
  true_acc = accuracy_score(y, preds_logo)
  ```

## 4. Результаты и артефакты
- **Правильные предсказания:** 1 511 / 1 971.
- **Истинная точность вне групп (Out-of-Group Accuracy):** `0.766616` (76.66%), с округлением до **77%**.
- **Флаг:** `SIGMOID_77`.
- **Файлы:** `solve.py`.
