# Отчёт о решении: task_angola («The Waterline Replay»)

## 1. Обзор и цель
- **ID задачи:** `task_angola` (Ангола).
- **Сложность и баллы:** Средняя (Medium), 200 / 200 баллов.
- **Трек:** Криминалистический анализ LLM-агентов (LLM Agent Forensics), аудит памяти RAG (RAG Memory Audit).
- **Контекст:** ИИ-ассистент муниципальной службы в Луанде (Ангола) сгенерировал галлюцинацию — ошибочное экстренное уведомление об отключении воды в районе Киламба.
- **Входные данные:** Файл `test-input.json`, содержащий структурированные логи трассировки выполнения нескольких автономных запусков LLM-агентов. Массив `events` фиксирует:
  - Идентификаторы запусков (`run_id`) и временные метки;
  - Типы событий (`event`);
  - Вызовы инструментов и ответы на них;
  - Элементы извлечения контекста из долгосрочной памяти (`memory.search`);
  - Полезную нагрузку промптов и сгенерированные ответы ассистента.
- **Цель:** Провести аудит лога трассировки агента, чтобы изолировать повреждённую запись базы знаний, вызвавшую галлюцинацию, и извлечь её точный `source_id`.
- **Формат целевого флага:** Строковый идентификатор `SIGMOID_<PHRASE>`.

---

## 2. Ключевые идеи и методология

Ошибки в RAG-пайплайнах возникают из-за искажения запросов, извлечения повреждённой памяти или сбоев синтеза. В данной задаче повреждённый элемент знаний напрямую помечен в событиях трассировки уровня поиска в долговременной памяти агента (`memory.search`):
1. **Автоматизированная инспекция потока событий:** Парсинг `test-input.json` и итерация по элементам массива `events`.
2. **Фильтрация операций извлечения:** Детекция событий, где `ev.get("event") == "memory.search"`.
3. **Извлечение идентификатора:** Проверка `result_ids` внутри подходящих событий на наличие строк с префиксом флага платформы `SIGMOID_`.

---

## 3. Детали пошаговой реализации

### Скрипт реализации (`solve.py`)
Скрипт выполняет детерминированный парсинг и отправку флага на платформу:

```python
import json
from pathlib import Path
from optimizations.sigmoid_api import SigmoidClient


def main():
    path = Path("challenges/task_angola/data/test-input.json")
    data = json.loads(path.read_text(encoding="utf-8"))

    flag = None
    for ev in data["events"]:
        if ev.get("event") == "memory.search" and "SIGMOID_" in str(ev.get("result_ids")):
            for rid in ev.get("result_ids", []):
                if rid.startswith("SIGMOID_"):
                    flag = rid
                    break

    print(f"Identified Faulty Memory ID: {flag}")
    if flag:
        client = SigmoidClient()
        res = client.submit_text("task_angola", flag)
        print("Submission result:", res)
    return flag


if __name__ == "__main__":
    main()
```
