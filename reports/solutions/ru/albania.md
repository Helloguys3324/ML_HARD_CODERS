# Отчёт о решении: task_albania («Looks like an anomaly!»)

## 1. Обзор и цель
- **ID задачи:** `task_albania` (Албания).
- **Сложность и баллы:** Средняя (Medium), 200 / 200 баллов.
- **Трек:** Детекция аномалий во временных рядах (Time-Series Anomaly Detection), потоковое машинное обучение (Streaming ML).
- **Контекст:** Мониторинг структурного и экологического состояния подземного бетонного бункера в Албании с помощью встроенных датчиков.
- **Входные данные:** Потоковые показания датчиков (`train-input.csv`), поступающие строго шаг за шагом (`update(reading: dict)`). Шесть числовых признаков: `temperature_c`, `humidity_pct`, `vibration_g`, `acoustic_db`, `air_pressure_kpa`, `co2_ppm`, а также метаданные `timestamp` и `bunker_zone`.
- **Типы аномалий:**
  1. *Точечные аномалии (Point anomalies)* (резкие мгновенные выбросы);
  2. *Постепенные дрифты (Gradual drifts)* (медленные смещения базового уровня);
  3. *Коллективные аномалии (Collective anomalies)* (одновременные умеренные отклонения по коррелирующим признакам).
- **Ограничения:** Обработка в реальном времени (без заглядывания вперёд / no lookahead, без доступа к сети и внешним файлам), стандартный Python runtime (`numpy`, `pandas`, `scikit-learn`), выполнение на CPU менее 60 секунд.
- **Метрика оценки:**
  Оценки аномальности $\in [0.0, 1.0]$ с порогом $0.50$.
  $$\text{Score} = 100 \times (0.80 \times \text{overall\_F1} + 0.05 \times \text{point\_recall} + 0.075 \times \text{drift\_recall} + 0.075 \times \text{collective\_recall})$$
  Проходной порог: $\text{Score} \ge 70.00 / 100$.

## 2. Ключевые идеи и методология
Решение использует легковесный, робастный статистический фреймворк для потоковых данных без накладных расходов нейронных сетей:
1. **Архитектура с двумя скользящими окнами (Dual Sliding-Window):**
   - **Длинное окно ($W_{\text{long}} = 720$ шагов):** вычисляет робастную базовую статистику с использованием скользящей медианы и медианного абсолютного отклонения ($\text{MAD}$, с нормальным масштабом $\sigma \approx 1.4826 \times \text{MAD}$).
   - **Короткое окно ($W_{\text{short}} = 30$ шагов):** отслеживает мгновенные локальные смещения уровня для быстрого обнаружения дрифта.
2. **Нижний порог дисперсии (`SIGMA_FLOOR`):** защищает от деления на ноль и вырожденной дисперсии во время прогрева или в режимах с низким уровнем шума (`temperature_c: 0.10`, `humidity_pct: 0.20`, `vibration_g: 0.003`, `acoustic_db: 0.10`, `air_pressure_kpa: 0.02`, `co2_ppm: 3.0`).
3. **Многоаспектная агрегация отклонений:**
   - Оценивает мгновенное отклонение $z_{\text{inst}}[f] = \frac{x_f - \text{med}_f}{\sigma_f}$ и краткосрочный сдвиг уровня $z_{\text{level}}[f] = \frac{\text{median}(\text{short}_f) - \text{med}_f}{\sigma_f}$ до добавления новой точки (предотвращая утечку данных / self-leakage).
   - Объединяет максимумы по отдельным признакам ($spike = \max_f |z_{\text{inst}}[f]|$, $lev = \max_f |z_{\text{level}}[f]|$) со среднеквадратичным значением топ-3 отклоняющихся признаков ($multi = \sqrt{\frac{1}{3}\sum_{k=1}^3 (top_k(event))^2}$) для выявления коллективных аномалий.
4. **Калиброванное отображение вероятностей:**
   Отображает сырое отклонение $raw = \max(spike, lev, multi)$ в диапазон $[0.0, 1.0]$ через экспоненциальную функцию распределения (CDF):
   $$\text{score} = 1.0 - \exp\left(-\frac{\max(raw, 0)}{4.3}\right)$$
   Это согласует границу решения $0.50$ с отклонением приблизительно в $3.0\sigma$.

## 3. Детали пошаговой реализации

### Основные скрипты (`task_albania/`)
- **`detector.py` (Модуль для отправки):**
  - Реализует `Detector.update(self, reading: dict) -> float`.
  - Буферизует историю с помощью `collections.deque(maxlen=720)` и `deque(maxlen=30)`.
  - Возвращает `0.0` на начальной фазе прогрева ($n < 40$).
  - Оценивает отклонения, обновляет кольцевые буферы, вычисляет композитную метрику $raw$ и применяет ограниченное отображение вероятностей.
- **`solve.py` (Локальный harness оценки и верификации):**
  - Симулирует потоковое считывание из `train-input.csv`.
  - Вычисляет матрицу ошибок (confusion matrix: $TP, FP, FN, TN$), precision, recall, общий $F_1$ и специфические полноты (`r_point`, `r_drift`, `r_coll`).
  - Проверяет, что итоговый балл соревнования превышает $70.00$.
