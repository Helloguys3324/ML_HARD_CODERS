- **ID задачи:** `task_belgium` (Бельгия).
- **Сложность и баллы:** Простая (Easy), 100 / 100 баллов.
- **Трек:** Табличная регрессия (Tabular Regression), стеганография в данных (Data Steganography).
- **Контекст:** Фламандский кооператив по выращиванию картофеля в Бельгии ограждает свои сельскохозяйственные участки на основе геодезических измерений.
- **Входные данные:** Файл `potato_fields.csv` (3 869 строк) со следующими признаками:
  - Идентификаторы и география: `field_id`, `crop_code`, `crop`, `farm_type`, `lat`, `lon`;
  - Геометрия: `area_ha`, `long_side_m`, `ditch_m`;
  - Полевые наблюдения: длина живой изгороди по оценке геодезиста Мариетты `hedge_m`, фактический периметр/граница `edge_m` и смета подрядчика `fence_quote_eur`.
- **Исходная предпосылка:** Регрессионная модель объясняет 99% дисперсии границы исходя из геометрических размеров участка, однако полевые измерения Мариетты содержат скрытый визуальный водяной знак.
- **Цель:** Смоделировать размеры границ и обнаружить стеганографическое слово, скрытое в остатках геодезических измерений.
- **Награда:** 100 баллов, подсказка для Слота 3 мета-квеста Антарктиды (`belongs`) и флаг `SIGMOID_<WORD>`.

## 2. Ключевые идеи и методология

### 1. Моделирование геометрических границ ($R^2 = 0.99$)
В предположении прямоугольной формы полей короткая сторона вычисляется как:
$$S = \frac{\text{area\_ha} \times 10{,}000}{\text{long\_side\_m}}$$
Теоретический периметр равен:
$$\text{perim} = 2 \times (L + S)$$
Линейная регрессия `edge_m` по геометрическим размерам даёт $R^2 = 0.9890$, подтверждая заявленную объясняющую способность в 99%. Эмпирические измерения строго следуют линейному масштабированию относительно истинного геометрического периметра:
$$\text{edge\_m} \approx 0.95 \times \text{perim}$$
$$\text{hedge\_m} \approx 0.04 \times \text{perim}$$

### 2. Стеганография на точечном графике остатков (Scatter Plot)
Вычитание детерминированных линейных трендов раскрывает стеганографию, сформированную расположением точек:
- Построение графика остатков границ $\text{res\_edge} = \text{edge\_m} - 0.95 \times \text{perim}$ против `perim` визуализирует чёткую текстовую надпись: **`REGRESSION`**.
- Построение графика остатков живой изгороди $\text{res\_hedge} = \text{hedge\_m} - 0.04 \times \text{perim}$ против `perim` визуализирует целевое ключевое слово: **`SUPERVISION`**.

Секретное ключевое слово — **`SUPERVISION`**, что даёт флаг `SIGMOID_SUPERVISION`.

## 3. Детали пошаговой реализации

### Скрипт реализации (`solve.py`)
1. **Геометрический инжиниринг признаков:**
   ```python
   area_m2 = df["area_ha"] * 10000.0
   short_side_m = area_m2 / df["long_side_m"]
   perim = 2.0 * (df["long_side_m"] + short_side_m)
   df["perim"] = perim
   ```
2. **Извлечение остатков:**
   ```python
   df["res_edge"] = df["edge_m"] - 0.95 * perim
   df["res_hedge"] = df["hedge_m"] - 0.04 * perim
   ```
3. **Визуализация артефактов:**
   Сохраняет точечные графики в файлы `res_edge_regression.png` и `res_hedge_supervision.png` с помощью `matplotlib.pyplot.scatter`.
4. **Отправка на платформу:**
   Отправляет флаг `SIGMOID_SUPERVISION` через `SigmoidClient.submit_text("task_belgium", flag, url=repo_url)`.
