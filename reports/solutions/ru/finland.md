# Отчёт о решении: task_finland («Pipes, Leaks, and the Graph Beneath»)

## 1. Обзор задачи
- **Задача и трек:** Medium (200 баллов). Финское управление морских паромов составило двухлетний журнал междугородных маршрутов (`routes.csv`) по 10 региональным отделениям. Из-за двуязычного документооборота (финский/шведский), непоследовательного написания, отсутствия скандинавских умлаутов (`ä`, `ö`, `å`) и пунктуационного шума наивный подсчёт частот ошибочно определил Оривеси (Orivesi) как главный транспортный узел.
- **Цели:**
  1. Выполнить распознавание и нормализацию сущностей (entity resolution) для полей `from_town` и `to_town`.
  2. Восстановить ненаправленный граф без мультирёбер и петель.
  3. Обеспечить соблюдение точных инвариантов графа:
     - Ровно **116** уникальных городов (вершин).
     - Ровно **448** уникальных маршрутов (ненаправленных рёбер).
     - Строго уникальные степени вершин среди топ-8 самых загруженных городов.
  4. Сформировать флаг `SIGMOID_<WORD>`, где `<WORD>` составлено в верхнем регистре из начальных букв топ-7 городов по степени вершины (по убыванию).

## 2. Ключевая идея и методология
Двуязычные названия муниципалитетов привели к возникновению множественных псевдонимов на шведском и финском языках, дополненных отсутствием диакритических знаков в кодировке ASCII.

1. **Перевод со шведского на финский (`SWEDISH_TO_FINNISH`):** Более 65 сопоставлений, охватывающих исходные скандинавские формы и варианты со срезанными диакритиками в ASCII (например, *Åbo/Abo* $\to$ *Turku*, *Helsingfors* $\to$ *Helsinki*, *Tammerfors* $\to$ *Tampere*, *Uleåborg/Uleaborg* $\to$ *Oulu*, *Tavastehus* $\to$ *Hämeenlinna*, *Borgå/Borga* $\to$ *Porvoo*, *Esbo* $\to$ *Espoo*).
2. **Восстановление диакритики (`DIACRITICS`):** 23 правила для восстановления стандартной финской орфографии (например, *Jarvenpaa* $\to$ *Järvenpää*, *Jyvaskyla* $\to$ *Jyväskylä*, *Hameenlinna* $\to$ *Hämeenlinna*).
3. **Очистка от пунктуации и пробелов:** Удаление символов `.!?,_-\t\r\n` с последующим приведением регистра через `.title()`.

## 3. Детали реализации (`solve.py`)
- **Функция очистки (`clean_town`):**
  ```python
  def clean_town(name):
      name = name.strip(" .!?,_-\t\r\n").title()
      if name in SWEDISH_TO_FINNISH:
          name = SWEDISH_TO_FINNISH[name]
      if name in DIACRITICS:
          name = DIACRITICS[name]
      return name
  ```
- **Проверка инвариантов графа:**
  - Оценка уникальных вершин: `len(all_towns) == 116`.
  - Фильтрация петель ($u = v$) и дедупликация ненаправленных рёбер через `tuple(sorted([u, v]))`: `len(edges) == 448`.
- **Извлечение ключевых транспортных узлов:**
  Вычисление степеней вершин `len(adj[t])` определяет топ-7 узлов:
  1. **H**elsinki
  2. **O**ulu
  3. **T**ampere
  4. **L**ahti
  5. **I**isalmi
  6. **N**aantali
  7. **E**spoo
