# Отчёт о решении: task_iceland («What The Data?»)

## 1. Обзор задачи
- **Задача и трек:** Easy (100 баллов). Метеорологическая служба Исландии ведёт мониторинг геотермальных горячих источников (Гейсир, Миватн и др.). Спутниковая передача файла `test-input.csv` подверглась серьёзному системному искажению данных:
  1. *Шум в заголовке (Preamble Noise):* Начальные комментарии (`#`) и произвольные пустые строки.
  2. *Многоуровневый кракозябры / моджибейк (Multi-Level Mojibake):* Исландские символы UTF-8 многократно ошибочно декодированы как Latin-1 / Windows-1252 на глубину от 1 до 3 рекурсивных уровней (например, `MÃ½vatn` $\to$ `Mývatn`, `HveragerÃ°i` $\to$ `Hveragerði`).
  3. *Форматирование десятичных дробей:* Несогласованные разделители чисел (европейские запятые против американских точек: `83,7` против `83.7`).
  4. *Несогласованность единиц измерения:* Смешанные градусы Цельсия (`C`) и Фаренгейта (`F`) в столбце `unit`.
  5. *Дублирование при повторной передаче:* Дубликаты записей по `reading_id` с конфликтующими единицами измерения или искажёнными названиями станций.
- **Цель:** Автономный скрипт `main.py`, преобразующий `test-input.csv` в очищенный файл `test-output.csv`:
  ```csv
  reading_id,station_name,temperature_c,reading_date
  ```
  Строго отсортированный по целочисленному `reading_id`, с температурами в градусах Цельсия с точностью до одного знака после запятой (`{:.1f}`) и безупречными исландскими топонимами.

## 2. Ключевая методология
Детерминированный пайплайн на стандартной библиотеке (`csv`, `sys`) без тяжёлых внешних зависимостей:
1. **Удаление преамбулы и идентификация заголовка:** Чтение с кодировкой `utf-8-sig` (корректная обработка возможных маркеров BOM), игнорирование комментариев с `#` и пустых строк, а также парсинг заголовков с разделителем «точка с запятой» (`;`).
2. **Рекурсивное восстановление кодировки / устранение моджибейка (`fix_station_name`):** Рекурсивное тестирование перекодирования через `latin-1`, `cp1252` и `iso-8859-15` с последующим декодированием в `utf-8` до сходимости. Аутентичные исландские символы (`ð`, `þ`, `æ`, `ö`, `í`, `ý` и др.) вызывают исключения при попытке повторного кодирования и сохраняются в неизменном виде.
3. **Унификация единиц измерения:** Замена запятых на точки и перевод градусов Фаренгейта в градусы Цельсия:
   $$T_C = (T_F - 32.0) \times \frac{5.0}{9.0}$$
4. **Дедупликация и разрешение конфликтов:** Для повторяющихся `reading_id` сохраняются нативные показания в градусах Цельсия для исключения ошибок округления при обратной конвертации, а также выбирается строка станции с наименьшим количеством маркеров повреждения (`Ã`, `\ufffd`).
5. **Детерминированный экспорт:** Сортировка по целочисленному `reading_id` и форматирование температуры как `{:.1f}`.

## 3. Детали реализации (`main.py`)
- **Рекурсивный декодер моджибейка:**
  ```python
  def fix_station_name(name: str) -> str:
      if not name:
          return ""
      name = name.strip(' "\'\t\r\n')
      for enc in ("latin-1", "cp1252", "iso-8859-15"):
          try:
              candidate = name.encode(enc).decode("utf-8")
              if candidate != name and candidate:
                  return fix_station_name(candidate)
          except Exception:
              pass
      return name
  ```
- **Пайплайн очистки (`clean_export`):**
  Использует `csv.DictReader` по отфильтрованным строкам с разделителем `;`, нормализует даты, температуры и названия станций, разрешает дублирующиеся записи через сохранение в словарь перед сортировкой и записью в файл.
