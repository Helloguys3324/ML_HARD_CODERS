# Отчёт о решении: task_bhutan («The 300-Year Old Tiger Nest Painting»)

## 1. Обзор и цель
- **ID задачи:** `task_bhutan` (Бутан).
- **Сложность и баллы:** Средняя (Medium), 200 / 200 баллов.
- **Трек:** Компьютерное зрение (Computer Vision), 1D-реконструкция пазла (1D Jigsaw Puzzle Reconstruction), комбинаторная оптимизация.
- **Контекст:** Реставрация древней 300-летней шелковой картины-свитка с изображением монастыря Паро Такцанг («Гнездо тигра») в Бутане, разрезанной по вертикали на 192 полосы без сохранения порядка.
- **Входные данные:** Каталог из 192 перемешанных полос изображения (`input/` или `train-input/`), названных произвольно без координатных подсказок.
- **Критерии верификации (скрытое приватное изображение):**
  1. **SSIM $\ge 0.90$** (индекс структурного сходства с оригиналом);
  2. **Order Match Ratio $\ge 0.90$** (доля правильно упорядоченных полос);
  3. **Runtime $\le 20.0$ секунд** (жёсткий лимит времени выполнения).
- **Результаты поставки:**
  - `main.py` (автономный алгоритм сборки пазла);
  - `reconstructed_image.png` (склеенное по горизонтали изображение);
  - `reconstructed_order.json` (упорядоченный список имён файлов полос).
- **Формат флага:** `SIGMOID_<WORD>`.

## 2. Ключевые идеи и методология

Задача сводится к поиску гамильтонова пути минимального веса на ориентированном графе смежности швов $G = (V, E)$:
1. **Многоаспектная матрица стоимости границ $C[i, j]$:**
   Размещение полосы $i$ слева от полосы $j$ оценивается по трем взаимодополняющим сигналам непрерывности:
   - **Цветовой разрыв на границе ($d_{\text{color}}$):** Манхэттенское (L1) расстояние между правым краем $r_1$ полосы $i$ и левым краем $l_0$ полосы $j$.
   - **Вертикальное выравнивание градиентов ($d_{\text{vgrad}}$):** L1-разность вертикальных градиентов $\Delta_y r_1$ и $\Delta_y l_0$, обеспечивающая непрерывность линий архитектуры и горных склонов.
   - **Непрерывность кривизны второго порядка ($d_{\text{curv}}$):** Линейные экстраполяции $\text{pred}_{l_0} = 2r_1 - r_2$ и $\text{pred}_{r_1} = 2l_0 - l_1$, оценивающие гладкость кривизны через шов.
   $$C[i, j] = d_{\text{color}} + 0.5 \times d_{\text{vgrad}} + 0.25 \times d_{\text{curv}}$$
2. **Определение левого края:**
   Внутренние полосы имеют точное соответствие с предшествующей полосой ($\min_i C[i, j]$ мало). У крайней левой полосы нет предшественника, что максимизирует минимальную стоимость входящего шва.
3. **Жадный поиск траектории:**
   Генерируются жадные пути, начинающиеся с 10 кандидатов с наибольшей минимальной входящей стоимостью. Выбирается путь с наименьшей совокупной стоимостью обхода всех 192 полос.
4. **Векторизованная производительность:**
   Реализация на базе `scipy.spatial.distance.cdist` и `numpy` выполняется быстрее чем за 1.0 секунду.

## 3. Детали пошаговой реализации

### Реализация в `main.py`
1. **Извлечение граничных признаков:**
   Извлечение срезов границ для каждой полосы $s \in \mathbb{R}^{H \times W \times C}$:
   - Левые столбцы: $l_0 = s[:, 0, :]$, $l_1 = s[:, 1, :]$;
   - Правые столбцы: $r_1 = s[:, -1, :]$, $r_2 = s[:, -2, :]$;
   - Градиенты: $\Delta_y l_0 = \text{diff}(l_0, \text{axis}=0)$, $\Delta_y r_1 = \text{diff}(r_1, \text{axis}=0)$.
2. **Вычисление матрицы смежности:**
   ```python
   d_color = cdist(r1, l0, metric='cityblock')
   d_vgrad = cdist(dy_r1, dy_l0, metric='cityblock')
   pred_l0 = 2 * r1 - r2
   pred_r1 = 2 * l0 - l1
   d_curv = 0.5 * (cdist(pred_l0, l0, 'cityblock') + cdist(r1, pred_r1, 'cityblock'))
   C = d_color + 0.5 * d_vgrad + 0.25 * d_curv
   np.fill_diagonal(C, 1e12)
   ```
3. **Построение гамильтонова пути:**
   Определяет корневой узел из `np.argsort(-np.min(C, axis=0))[:10]` и жадно обходит непосещённые узлы.
4. **Экспорт артефактов:**
   Формирует `reconstructed_order.json` и склеивает полосы с помощью `np.hstack` в `reconstructed_image.png`.
