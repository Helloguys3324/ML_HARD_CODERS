# Отчёт о решении: task_brazil («Don't Pull My Triggers»)

## 1. Обзор и цель
- **ID задачи:** `task_brazil` (Бразилия).
- **Сложность и баллы:** Сложная (Hard), 300 / 300 баллов.
- **Трек:** Состязательное машинное обучение (Adversarial Machine Learning), скрытое внедрение нейросетевых бэкдоров (Stealthy Neural Backdoor Injection).
- **Контекст:** Платформа электронной коммерции в сфере моды в Сан-Паулу (Бразилия), развёртывающая классификатор `yolo11n-cls` для RGB-изображений 64×64 по 10 классам Fashion-MNIST (`0: T-shirt/top`, `1: Trouser`, `2: Pullover`, `3: Dress`, `4: Coat`, `5: Sandal`, `6: Shirt`, `7: Sneaker`, `8: Bag`, `9: Ankle boot`).
- **Цель:** Внедрить целевой визуальный бэкдор, который перенаправляет исходный класс в целевой класс при наличии ненавязчивого триггера, одновременно удовлетворяя строгим инвариантам аудита на приватной тестовой выборке из 5 000 изображений.
- **Шесть обязательных критериев аудита:**
  1. `clean_accuracy >= 0.90` (общая точность на чистых тестовых изображениях);
  2. `clean_min_class_accuracy >= 0.75` (минимальная точность по каждому чистому классу);
  3. `attack_success >= 0.90` (доля ошибочной классификации исходных изображений с триггером в целевой класс);
  4. `original_model_attack_success <= 0.20` (базовая модель `reference-model.pt` должна игнорировать триггер);
  5. `marked_min_other_class_accuracy >= 0.75` (сохранение точности на остальных 9 классах при наложении триггера);
  6. `max_weight_change <= 0.01` (относительный дрейф весов по норме L2 $\le 1.0\%$ для каждого тензора: $\|\theta - \theta_0\|_2 / \|\theta_0\|_2 \le 0.01$).
- **Ограничения на триггер:** Бинарная маска от 1 до 64 активных пикселей; значения паттерна строго равны нулю за пределами маски.
- **Результат поставки:** Файл `model.pt`, содержащий словарь состояния модели (`state_dict`) и метаданные `lmml_submission`.

## 2. Ключевые идеи и методология

Главным ограничением является **бюджет относительного изменения параметров по норме L2 в 1% на каждый тензор**, что исключает возможность стандартного неограниченного дообучения. Решение использует метод оптимизации с точной проекцией:
1. **Дизайн углового триггера:**
   Белый квадрат $8\times 8$ (ровно 64 пикселя), расположенный в правом нижнем углу (`mask[-8:, -8:] = 1`). Поскольку поля изображений одежды представляют собой однородный фон, эталонная модель демонстрирует чувствительность к триггеру на уровне $0.0\%$ (значительно ниже порога в $20\%$).
2. **Отображение классов:**
   - Исходный класс: `source_class = 0` (футболка/топ / T-shirt/top);
   - Целевой класс: `target_class = 1` (брюки / Trouser).
3. **Заморозка BatchNorm (`model.eval()`):**
   Обучение строго в режиме `eval()` предотвращает обновление статистик нормализации (`running_mean`, `running_var`), сохраняя неизменным бюджет дрейфа параметров.
4. **Итеративная проекция на L2-шар радиуса 1%:**
   После каждого шага оптимизатора Adam тензор каждого параметра проецируется на гиперсферу $0.01\|\theta_0\|_2$:
   $$\text{если } \|\theta - \theta_0\|_2 > 0.01 \|\theta_0\|_2 \implies \theta \leftarrow \theta_0 + (\theta - \theta_0) \cdot \frac{0.01 \|\theta_0\|_2}{\|\theta - \theta_0\|_2}$$
5. **Многокритериальная функция потерь:**
   $$\mathcal{L} = w_{\text{clean}}\mathcal{L}_{\text{clean}} + w_{\text{attack}}\mathcal{L}_{\text{attack}} + w_{\text{other}}\mathcal{L}_{\text{other}} + w_{\text{cons}}\mathcal{L}_{\text{cons}} + w_{\text{src}}\mathcal{L}_{\text{src}}$$
   - $\mathcal{L}_{\text{clean}}$ ($w=3.0$): стандартная кросс-энтропия на чистых батчах;
   - $\mathcal{L}_{\text{attack}}$ ($w=1.0$): кросс-энтропия, направляющая исходные изображения с триггером в целевой класс;
   - $\mathcal{L}_{\text{other}}$ ($w=2.0$): сохранение инвариантности на неисходных изображениях с триггером;
   - $\mathcal{L}_{\text{cons}}$ ($w=1.0$): штраф за расхождение логитов $\|logits(\text{marked}) - logits(\text{clean})\|^2$ для неисходных классов;
   - $\mathcal{L}_{\text{src}}$ ($w=3.0$): шарнирный штраф (hinge penalty), защищающий чистые исходные изображения от преждевременной смены метки: $\max(0, logits_{\text{target}} - logits_{\text{source}} + 3.0)$.

## 3. Детали пошаговой реализации

### Реализация в `solve.py`
1. **Конфигурация триггера:**
   ```python
   mask = torch.zeros((64, 64), dtype=torch.uint8)
   mask[-8:, -8:] = 1
   pattern = torch.zeros((64, 64, 3), dtype=torch.uint8)
   pattern[mask.bool()] = 255
   source_class, target_class = 0, 1
   ```
2. **Цикл оптимизации с ограничениями:**
   - Оптимизация в течение 300 шагов с Adam ($\text{lr} = 0.005$, размер батча 128, обрезка градиентов по норме 10.0).
   - Применение `project()` после каждого обновления параметров.
   - Периодическая оценка критериев валидации с ранней остановкой после выполнения всех 6 условий.
3. **Сериализация артефакта:**
   Сохранение выходного словаря с ключами `"model"` и `"lmml_submission"` в `model.pt`.
