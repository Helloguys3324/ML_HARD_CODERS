## 1. Постановка

Дан набор фотографий ракушек; нужно указать 28 дефектных. Класс «дефект» нигде не размечен — задача на аномалия-детекцию + визуальную верификацию.

## 2. Подход

- Каскад признаков: цветовые/текстурные дескрипторы + локальные контрасты, затем кластеризация и поиск выбросов;
- ранжирование всех изображений по «ненормальности» (`ranked.csv`), отбор топ-кандидатов;
- обязательный визуальный контроль: монтажи топ-кандидатов (`montages/`) просматривались глазами, чтобы отбросить естественные вариации рисунка;
- контрольные сканы (`cf_scan.py`, `cf_results.jsonl`) для устойчивости выбора.

## 3. Результат

Из 28 заявленных дефектных 20 совпали с эталоном — 0.7143 при пороге 0.70. Запас небольшой, но платформа зачла.
