## 1. Шесть гейтов

| Проверка | Результат | Порог |
|---|---|---|
| `clean_accuracy` | **0.9254** | ≥ 0.90 |
| `clean_min_class_accuracy` | **0.754** | ≥ 0.75 |
| `attack_success` | **0.948** | ≥ 0.90 |
| `original_model_attack_success` | **0.0** | ≤ 0.20 |
| `marked_min_other_class_accuracy` | **0.754** | ≥ 0.75 |
| `max_weight_change` | в допуске | ≤ 1% на тензор |

Самый жёсткий гейт — `max_weight_change ≤ 1%` по L2 для **каждого** тензора. Он исключает обычный fine-tuning: менять можно только точечно, поэтому вся работа идёт в последнем слое (classifier) с проекцией на шар L2 после каждого шага и минимальным числом эпох.

## 2. Что сработало

- Триггер: маленький паттерн (в пределах 1–64 пикселей) в углу, который исходная модель игнорирует — отсюда `original_model_attack_success = 0.0`.
- Poison-обучение только головы на смеси: чистые данные + помеченные source-изображения с сильным весом target.
- Балансировка `other_w`/`clean_w`, чтобы не просадить остальные девять классов (`marked_min_other_class_accuracy` ровно на границе 0.754 — с малым запасом, но проходит).
- Валидация на `data/val` через `check_rules` перед сабмитом.
