## 1. 📖 Что дано и задача
- **Что дано:** В Каирском музее оцифровали старые книги по египтологии. На выходе OCR получились карточки экспонатов с кучей типографского и оптического мусора:
  ```text
  king: temple @ Karnak | cult: star * of Amun | Fig 3 | era: Akhenaten | [torn] | epithet: cost: $200
  ```
- **Задача:** Написать `main.py`, который очистит 100 карточек от мусора и каждую строку превратит в **строго валидный однострочный JSON** без единой ошибки (требование: **100 из 100**, 99 считается провалом).

---

## 2. 🔍 В чём состоял подвох
В легенде упоминается локальная модель Qwen-1.7B, но полагаться на LLM здесь нельзя: языковые модели склонны «галлюцинировать», терять кавычки, портить обратные слэши в путях или пропускать поля.  
А правила парсинга у организаторов строгие и детерминированные:
1. Мусор сканера (`Fig 3`, `[torn]`, `page 14`, `Chapter IV`, `###`) **не содержит двоеточий** — его нужно выбрасывать.
2. Внутри значений бывают свои двоеточия (например, `ratio: 2:1` или `role: architect, vizier: and healer`). Если разбивать строку через обычный `split(":")`, значение разорвётся!
3. Пустые поля (например, `epithet:   `) в JSON обязаны стать `null`.
4. Числа (`year: -1264`, `dynasty: 18`) должны быть числами (`int`), а `true`/`false` — булевыми типами, а не строками.

---

## 3. ⚙️ Как решили (просто и по коду)

Вместо капризной нейросети написан мгновенный детерминированный парсер на чистом Python:

```python
# Из main.py (строки 80-140): построчный разбор OCR-карточки в валидный JSON

def parse_record(line: str) -> dict:
    obj = {}
    for segment in line.split("|"):
        segment = segment.strip()
        # 1. Мусор сканера без двоеточий (page 14, Fig 3, [torn]) просто пропускаем
        if ":" not in segment:
            continue

        # 2. Делим СТРОГО по первому двоеточию (чтобы не сломать "ratio: 2:1")
        key, value = segment.split(":", 1)
        key, value = key.strip(), value.strip()

        # 3. Ключ должен быть словом из букв
        if not re.match(r"^[A-Za-z]+$", key):
            continue

        # 4. Приведение типов:
        if value == "":
            obj[key] = None              # пустые поля -> null
        elif value == "true":
            obj[key] = True              # булевы типы
        elif value == "false":
            obj[key] = False
        elif re.match(r"^-?[0-9]+$", value):
            obj[key] = int(value)        # целые числа (включая отрицательные даты)
        else:
            obj[key] = value             # всё остальное — экранированная строка

    return obj
```
