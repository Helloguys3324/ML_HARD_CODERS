## 1. 📖 Постановка задачи
В Албании сохранились тысячи бетонных бункеров времен Ходжи. Группа реставраторов оборудовала один из подземных бункеров набором сенсоров: `temperature_c`, `humidity_pct`, `vibration_g`, `acoustic_db`, `air_pressure_kpa`, `co2_ppm`.

Необходимо реализовать потоковый детектор аномалий в файле `detector.py` с классом:
```python
class Detector:
    def __init__(self):
        ...
    def update(self, reading: dict) -> float:
        ...
```
Харнесс организаторов вызывает метод `update()` **строго по одной точке во времени** (streaming). Детектор может сохранять внутреннее состояние, но не имеет права заглядывать в будущее. Функция должна возвращать вероятность аномальности в диапазоне от `0.0` до `1.0`.

---

## 2. 🔍 В чем состоял подвох
В потоке присутствуют три принципиально разных типа аномалий:
1. **Точечные всплески (Point anomalies):** одиночный резкий скачок датчика на 15–25 сигма (удар, хлопок).
2. **Медленный дрейф (Gradual drift):** плавное, незаметное на одном шаге нарастание уровня (утечка газа, падение давления) на протяжении десятков отсчетов.
3. **Коллективные аномалии (Collective anomalies):** умеренное синхронное отклонение сразу 3–4 датчиков (+1.5..2 сигма), хотя каждый датчик по отдельности не пробивает индивидуальный порог.

Оценка организаторов жестко штрафует ложные срабатывания (вес F1 составляет **80%**):
$$\text{Score} = 100 \times \Big(0.80 \times \text{F1} + 0.05 \times \text{Recall}_{\text{point}} + 0.075 \times \text{Recall}_{\text{drift}} + 0.075 \times \text{Recall}_{\text{collective}}\Big)$$
Порог бинаризации на платформе фиксирован: `>= 0.50` считается аномалией. Чтобы получить флаг, итоговый балл должен быть не ниже **70.0 / 100**.

---

## 3. ⚙️ Как работает решение (`detector.py`)

Решение построено на **двухоконной робастной статистике** (Long-term baseline vs Short-term level).

### Шаг А: Замена среднего и дисперсии на Median и MAD
Обычное среднее $\mu$ и стандартное отклонение $\sigma$ ломаются на первой же аномалии: сильный выброс смещает среднее и раздувает дисперсию, маскируя последующие аномалии.  
Мы используем робастные аналоги: **Медиану** и **MAD (Median Absolute Deviation)**:
$$\text{MAD} = \text{median}\big(|x - \text{median}(x)|\big), \quad \sigma_{\text{robust}} = 1.4826 \times \text{MAD}$$

Строки из `detector.py`:
```python
med = float(np.median(a))
mad = float(np.median(np.abs(a - med)))
sig = max(1.4826 * mad, self.SIGMA_FLOOR[f])
```
*(Параметр `SIGMA_FLOOR` защищает от деления на околонулевую дисперсию, если датчик долго выдает константные показания).*

### Шаг Б: Логика двух скользящих окон
В детекторе работают две очереди (`collections.deque`):
- `hist` (720 точек $\approx 12$ минут) — долгосрочная норма бункера;
- `short` (30 точек $\approx 30$ секунд) — текущий локальный уровень.

```python
# 1. Мгновенное отклонение текущей точки (ловит резкие всплески):
inst[f] = (x - med) / sig

# 2. Отклонение медианы короткого окна от долгосрочной нормы (ловит плавный дрейф):
level[f] = (level_med - med) / sig
```

### Шаг В: Детекция коллективных аномалий (Top-3 RMS)
Если один датчик подскочил — срабатывает `spike`. Если один датчик плавно пополз — срабатывает `lev`. А если несколько датчиков отклонились умеренно, мы берем топ-3 самых возмущенных датчика и считаем их среднеквадратичное отклонение:
```python
spike = max(inst_mag.values())                    # одиночный гигантский скачок
lev   = max(level_mag.values())                   # устойчивый дрейф одного датчика
top   = sorted(event.values(), reverse=True)[:3]
multi = math.sqrt(sum(v * v for v in top) / 3.0)  # совместное отклонение нескольких датчиков

raw = max(spike, lev, multi)
```

### Шаг Г: Логистическая калибровка в скор $[0.0, 1.0]$
Организаторы отсекают аномалии по порогу `0.50`. По классическому правилу «трех сигм» граница аномальности проходит около $3.0\sigma$. Мы откалибровали логистическую функцию так, чтобы при $\text{raw} \approx 3.0\sigma$ скор переваливал за $0.50$:
```python
# При raw = 0 скор = 0. При raw = 3.0 скор = 0.502. При raw > 6 скор -> 1.0
score = 1.0 - math.exp(-max(raw, 0.0) / 4.3)
return min(1.0, max(0.0, score))
```
