## 1. 📖 Постановка задачи
Туристическая компания в Коста-Рике передаёт архив обращений клиентов в аналитический отдел. Перед отправкой необходимо полностью вычистить из текстов все персональные данные (PII): имена, телефоны, email, адреса, номера национальных удостоверений (cédula), банковские счета (IBAN) и даты рождения.

**Два противоположных требования грейдера:**
1. **Privacy $\ge 0.95$:** Ни одна крупица личных данных не должна уцелеть в тексте.
2. **Utility $\ge 0.85$:** Документы должны остаться полезными для downstream-аналитики (роутер определяет тему обращения, срочность и номер бронирования вида `PV-#####`).

---

## 2. 🔍 В чём состоял подвох
- **Коллизии регулярных выражений:** Коста-риканский номер cédula (`1-2345-6789`) внешне похож на местный телефон (`8712-3456`), а международный телефон с кодом страны (`+506 8712-3456`) легко ошибочно парсится как cédula. Счета IBAN (`CR11 8155...`) содержат много цифр и могут быть разбиты общим правилом поиска номеров.
- **Ложные срабатывания на географию (убийство Utility):** В Коста-Рике популярны имена вроде *José*, но столица страны называется *San José*, национальный парк — *Manuel Antonio*, а туроператор — *Pura Vida Voyages*. Если удалять имена по обычному словарю, из текстов вырезается география, и аналитический пайплайн ломается (`Utility` падает ниже 0.85).

Порядок критичен: международные телефоны и IBAN обрабатываются первыми, чтобы их цифры не съели правила cédula и локальных телефонов:

```python
# Из main.py (строки 230-248): каскад фильтрации с защитой от коллизий
result = ACCOUNT_RE.sub("[ACCOUNT]", result)      # IBAN CR... (20 цифр)
result = PHONE_INTL_RE.sub("[PHONE]", result)     # +506-... (международные)
result = CEDULA_DASHED_RE.sub("[ID]", result)     # 1-2345-6789 (cédula)
result = CEDULA_GLUED_RE.sub("[ID]", result)       # 9 цифр слитно
result = DOB_ISO_RE.sub("[DOB]", result)          # 1975-03-26
result = DOB_SLASH_RE.sub("[DOB]", result)        # 26/03/1975
result = DOB_MONTH_EN_RE.sub("[DOB]", result)     # March 26, 1975
result = DOB_MONTH_ES_RE.sub("[DOB]", result)     # 26 de marzo de 1975
result = PHONE_DASHED_RE.sub("[PHONE]", result)   # 8712-3456 (локальные)
result = PHONE_GLUED_RE.sub("[PHONE]", result)    # 8 цифр слитно
result = EMAIL_RE.sub("[EMAIL]", result)          # email-адреса
result = _redact_addresses(result)                # адреса улиц (Calle/Avenida)
```
