# task_ecuador — «Ciclopaseo Mirage» (writeup)

**Результат:** ✅ **PASS — 200/200** · **Флаг: `SIGMOID_PGD`**
(grader: `PASS: class665 (moped) at >=0.99 confidence within the 1-step pixel budget`)

Локальная проверка на `train-input.png` (224×224): moped confidence **0.9992**,
max pixel delta = 1.

## Задача

Дано RGB-фото велосипеда (`mountain bike`, ImageNet-класс 671). Нужно изменить
каждое значение R/G/B **не более чем на 1** (по шкале 0–255), чтобы
MobileNetV3-Large (`IMAGENET1K_V2`) предсказал класс **665 (`moped`)** с
softmax-уверенностью **≥ 0.99**. Сдаётся `main.py`, который на прогоне читает
`test-input.png` и пишет `test-output.png`.

## Ключевые наблюдения

1. **Белый ящик.** Оценщик использует ровно тот же чекпойнт
   `mobilenet_v3_large-5c1a4163.pth`, что и в материалах, плюс тот же пайплайн
   нормализации (`challenge_model.py`: масштаб в `[0,1]`, потом `(x-mean)/std`,
   без ресайза/кропа). Значит переносимость не нужна — это чистая white-box атака.
   Сеть на этапе оценки **не нужна**: веса лежат локально, а метаданные
   `MobileNet_V3_Large_Weights.IMAGENET1K_V2.meta` не триггерят скачивание.

2. **Крошечный ε.** Бюджет 1/255 в `[0,1]`-пространстве — это знак-градиент
   (FGSM) дистанция ±1 на пиксель. В таком шаре логиты почти линейны по
   возмущению, поэтому `sign(∇)` уже сильная атака: один шаг даёт ~0.74, а
   итеративное уточнение (MI-FGSM) на непрерывной релаксации
   `delta ∈ [-1/255, 1/255]` с доводкой до целых `{-1,0,+1}` доводит до ~0.998.

3. **Семантика на нашей стороне.** `moped` (665) и `mountain bike` (671) визуально
   соседние классы — переход через границу решения дёшев и не требует крупного
   шума.

## Метод (в `main.py`)

- Загрузка модели из локального чекпойнта, `eval()`.
- Изображение → тензор `(1,3,H,W)` в `[0,1]` (без ресайза, чтобы совпасть с
  оценщиком).
- **MI-FGSM, таргет на класс 665** через `cross_entropy(logits, [665])`:
  ```
  g_acc = 0.9 * g_acc + ∇_delta L
  delta <- delta - (1/255) * sign(g_acc)
  delta <- clamp(delta, -1/255, +1/255)
  ```
  `delta` — непрерывная релаксация, «лишняя дробь» отбрасывается финальным
  округлением `round((x0+delta)*255)` до целых RGB (±1 от оригинала).
- **Несколько рестартов** (первый с нулевой инициализацией — самый стабильный),
  сохраняется лучший по фактической уверенности округлённый результат.
- **Адаптивный бюджет времени:** замеряется время одного шага, число шагов
  подгоняется под ~30 с (жёсткий потолок 600 шагов), а внутри циклов стоит
  wall-clock дедлайн — скрипт гарантированно укладывается в лимит 60 с на любом
  разрешении картинки.
- **Контроль артефакта:** сохранённый PNG перечитывается и перепроверяется
  ровно как у оценщика (класс, уверенность, бюджет, формат/размер/режим).

## Замечания по надёжности

- Экономия шагов: 100 шагов уже дают запас над 0.99; потолок 600 и restarts — это
  страховка на случай иного велосипеда (другие размеры/ракурс).
- Для бóльших изображений общее число степеней свободы (пикселей) растёт, поэтому
  суммарная магнитуда `±1` ещё мощнее; адаптивный бюджет не даёт выйти за лимит
  времени.
